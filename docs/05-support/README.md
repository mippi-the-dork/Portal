# 05. Support and Troubleshooting

When Portal appears missing or a graph behaves unexpectedly, diagnose the exact graph, pin, and family rather than relying on matching names. These pages give reproducible steps for support and clearly identify the current release candidate’s compatibility and known limitations.

## What to know before proceeding

Every Portal route is **data-only and graph-local**. Native Blueprint pins and links remain the saved source of truth. The editor-only Portal UI is not a runtime data store.
