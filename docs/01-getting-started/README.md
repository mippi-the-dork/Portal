# 01. Getting Started

Portal makes data routes readable without creating variables or changing Blueprint runtime behavior. This section explains the editor extension and walks through your first graph-local family. Start in an editable Blueprint graph, create an Input from a data output, connect an Output to a compatible consumer, and confirm the count updates.

## What to know before proceeding

Every Portal route is **data-only and graph-local**. Native Blueprint pins and links remain the saved source of truth. The editor-only Portal UI is not a runtime data store.
